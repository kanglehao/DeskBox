# DeskBox 1.5.10

DeskBox 1.5.10 is a usability release for widget groups, with two new ways into search and the in-app update prompts removed. Widget groups used to show only part of their member names in the title, hiding the rest behind a scroll; every member now gets its own tab in a single row that fits the available width, long names truncate, and both navigation styles render identically. Each tab also carries a stable colour derived from the member's identity, so members read as distinct chips instead of one continuous strip, and in narrow widgets the unused icon slot gives way to the text so names are no longer squeezed down to a few characters. Alongside the title work, a widget can now be sorted by how often you open its items, and the search popup gains two entry points — a button on the main window title bar and a "Search" item in the tray menu — so the global hotkey is no longer the only way in. The in-app update detection is gone: the update service, its background check, the tray and popup notices, and the Settings update cards were removed, and DeskBox is updated by installing a newer package.

Release date: 2026-10-16. This is a customized build based on the GPL-3.0 DeskBox sources (upstream: [Tianyu199509/DeskBox](https://github.com/Tianyu199509/DeskBox)); it is published here for sharing and ships the x64 installer.

## Highlights

- **Every group member visible at once.** `WidgetGroupTitleSwitcher` lays the group's members out as one row of equal-width tabs sized to the available space, so the title no longer scrolls to reveal the rest of the names. The width heuristic clamps to a usable minimum and maximum, long names truncate with an ellipsis, and the Tabs and Stack navigation styles were unified onto the same presentation.
- **Colour-coded, readable tabs.** Each member receives a stable tint derived from its identity — the same member keeps the same colour across restarts, and members of one group do not repeat a colour. In narrow widgets the header cancels the native tab header's close-button clearance with its own margin and the unused icon slot's margin is overridden to zero, so the text keeps its width instead of collapsing to a few characters.
- **Sort by usage.** A new `Frequency` sort mode orders a widget's items by how often they have been opened. Opens are recorded when `OpenItemAsync` reports a handled open, counts are persisted through the existing batched mutation path, and items with no recorded count sort as zero.
- **Search entry points.** A search button sits on the main window title bar, and the tray menu gains a "Search" item; both reuse the existing `App.OpenSearchPopup()` popup with its single-instance reuse and UI-thread marshalling.
- **Update prompts removed.** The update service, its factory and store variant, the scheduled background check, the tray and popup update notices, and the Settings update cards were deleted, along with the now-dead update settings keys. Release notes viewing and the About page's version display remain.

### 主要更新

- **组合成员一次全部可见。** `WidgetGroupTitleSwitcher` 把成员排成一排等宽标签，按可用宽度自适应，标题不再需要滚动才能看到其余名称；宽度启发式有可用上下限，超长名称以省略号截断，Tabs 与 Stack 两种导航样式已统一到同一表现。
- **标签彩色区分、文字看得清。** 每个成员按身份获得稳定色块——同一成员跨重启保持同色，同组成员不重复用色；窄宽度下标题用自身负边距抵消原生标签头为关闭按钮预留的边距，并把未使用图标槽的边距覆盖为 0，文字因此保住宽度，不再缩到几个字符。
- **按使用次数排序。** 新增 `Frequency` 排序模式，按项目被打开的次数排列；打开动作在 `OpenItemAsync` 返回已处理时计数，计数走既有批处理持久化路径，无记录的项目按 0 处理。
- **搜索入口。** 主窗口标题栏新增搜索按钮，托盘菜单新增「搜索」项，二者复用现有 `App.OpenSearchPopup()` 弹窗，沿用其单例复用与 UI 线程 marshal。
- **移除升级检测与提示。** 更新服务及其工厂与商店变体、计划的后台检查、托盘与弹窗更新提示、设置页更新卡片均已删除，相关失效设置键一并清理；更新日志查看与「关于」页的版本显示保留。
